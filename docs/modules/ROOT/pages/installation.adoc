= Installation

Add to your `shard.yml`:

[source,yaml]
----
dependencies:
  authn:
    github: aloli-crystal/authn
    version: "~> 0.1"
----

Then run:

[source,bash]
----
shards install
----

== Dependencies

* https://github.com/jgaskins/bcrypt[bcrypt] -- password hashing
* https://github.com/arcage/crystal-email[crystal-email] (~> 0.6) -- email sending
* https://github.com/crystal-community/jwt[jwt] (~> 1.6) -- JWT tokens
