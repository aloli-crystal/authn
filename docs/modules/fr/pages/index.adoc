= Authn

Briques d'authentification pour Crystal, liees a aucun framework web.
Anciennement `kemal-auth`.

== Modules

[cols="1,3"]
|===
| Module | Description

| `Authn::Password`
| Hachage et validation BCrypt des mots de passe avec regles conformes CNIL (12+ caracteres, majuscule, minuscule, chiffre, caractere special)

| `Authn::Token`
| Generation et verification de tokens JWT

| `Authn::Session`
| Gestion des sessions via cookies HTTP, independante du framework

| `Authn::SmtpConfig`
| Configuration du serveur SMTP

| `Authn::PasswordReset`
| Recuperation de mot de passe par courriel

| `Authn::UserManager`
| Gestion des utilisateurs et invitations
|===
