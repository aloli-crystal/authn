= Utilisation

== Gestion des Mots de Passe

[source,crystal]
----
require "authn"

hash = Authn::Password.hash("MonMotDePasse1!")
Authn::Password.verify("MonMotDePasse1!", hash) # => true

errors = Authn::Password.validate("faible")
# => ["Le mot de passe doit contenir au moins 12 caracteres.", ...]
----

== Tokens JWT

[source,crystal]
----
token = Authn::Token.generate(
  secret: ENV["SESSION_SECRET"],
  sub: "1",
  email: "user@example.com",
  role: "admin"
)
payload = Authn::Token.decode(token, ENV["SESSION_SECRET"])
----

== Configuration SMTP

=== A l'Instanciation

[source,crystal]
----
smtp = Authn::SmtpConfig.new(
  host: "smtp.example.com",
  port: 587,
  username: "user@example.com",
  password: "secret",
  from_address: "noreply@example.com",
  from_name: "Mon Application",
  use_starttls: true
)
----

=== Variables d'Environnement

[cols="1,2,1"]
|===
| Variable | Description | Defaut

| `SMTP_HOST` | Hote du serveur SMTP | `localhost`
| `SMTP_PORT` | Port SMTP | `587`
| `SMTP_USERNAME` | Nom d'utilisateur | _(vide)_
| `SMTP_PASSWORD` | Mot de passe | _(vide)_
| `SMTP_FROM_ADDRESS` | Adresse d'expedition | `noreply@example.com`
| `SMTP_FROM_NAME` | Nom d'expediteur | `Mon Application`
| `SMTP_TLS` | Activer TLS | `false`
| `SMTP_STARTTLS` | Activer STARTTLS | `true`
|===

== Recuperation de Mot de Passe

[source,crystal]
----
smtp = Authn::SmtpConfig.new(host: "smtp.example.com", ...)
result = Authn::PasswordReset.send_reset_email(
  email: "user@example.com",
  reset_url: "https://monapplication.fr/reset-password",
  secret: ENV["SESSION_SECRET"],
  smtp: smtp
)
----
